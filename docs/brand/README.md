# Moyami: identidad visual V1

Nombre elegido: Moyami. Dirección visual conservada: carbón, lima, lila y tipografía grande. El nuevo símbolo combina un paquete de snacks, una bebida y una chispa de descubrimiento. El dibujo del logo se presenta como propuesta para revisión.

## Archivos

- `svg/`: diez archivos vectoriales, con letras convertidas a trazados. No requieren fuentes instaladas para mostrar el logo. Versiones principal, compacta, vertical, símbolo, color, inversa y a una tinta.
- `png/`: exportaciones con transparencia y favicons en 16, 32, 48, 64 y 128 px.
- `moyami-guia-de-identidad-v1.pdf`: concepto, versiones, reglas básicas, sistema visual y siguientes pasos para la landing.
- `mascotas/`: sprites de Amy y Molly con GIF, WebP, APNG, cuadros individuales e imágenes estáticas.
- `brand-tokens.css` y `paleta.json`: colores y familias tipográficas para la implementación posterior.
- `licencias/`: referencias de las licencias de las familias tipográficas utilizadas.

## Uso

En un fondo claro, usar `moyami-principal-color.svg`. En fondo carbón, usar `moyami-principal-inverso.svg`. Para un solo color, elegir `moyami-principal-monocromo.svg` o `moyami-principal-blanco.svg` según el fondo. El símbolo puede usarse solo para un avatar o favicon.

Mantener las proporciones. Reservar alrededor del logo una separación equivalente a 1/8 de la altura del símbolo. Para lectura habitual, utilizar el logo principal con descriptor desde 480 px, el compacto sin descriptor desde 180 px y el símbolo desde 32 px; revisar visualmente el tamaño final. No estirar, inclinar ni cambiar los colores del logotipo.

Las mascotas acompañan al logo en comunicación y en la futura web. Los productos siguen usando sus empaques y marcas originales. La futura landing tendrá catálogo, ubicación y horarios; los datos comerciales deben confirmarse antes de publicarlos.
